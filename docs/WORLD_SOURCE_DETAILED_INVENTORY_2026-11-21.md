The original main Map layout measures **36,850 × 20,000 Construct units**. An ordinary map is **16×16** grid cells; later levels have a split **16×33** allocation with level-dependent placements.

**Do not report a total count of unique houses from these figures.** A location contains multiple sprites, and the original building can be expressed as exterior+interior+roof+collision objects. The complete 62-template raw catalog is generated by `tools/stage1/audit_original_world_catalog.py` in the source-audit workflow.

## Full world behavior that must not be omitted

Generation: all 62 location templates and their Array commands, roads and intersections, POI quotas and placements, water/shoreline, vegetation, bunkers, bridges, map reveal, heli crashes and world transitions.

Interactions: door frames and sound, shadows and collision; roofs and interior membership/layer opacity; tree HP, hit, fall, loot, hitbox, audio; berries and obstacles; loot and container spawning, pickup, drop and timed respawn; crafting, structures, stashes and resource states.

Living world: NPC/zombie and animal spawn conditions, AI, vehicle spawn/drive/collide, airdrops, quests, changing weather/day-night and persistent object state.

Visuals: every original PNG's exact Construct sprite-sheet **(x,y,width,height)** frame plus hotspot/imagepoint, animation timing, rotation, layer, opacity and collision shape. **Never draw the full sheet if the object references only a subrectangle.**

Audio: attach source cue selection/volume/timing/loop/stop to the exact event chain; presence of a WAV alone is not a connected effect.

## Reproducible detailed outputs

The committed `tools/stage1/audit_original_world_catalog.py` generates:

- `detailed-catalog/all_original_objects.csv` — EVERY original object ID, name, frame and animation count, plus provisional name-group candidates.
- `detailed-catalog/all_62_location_templates.csv` — all source branch UIDs, tile codes, event counts, Array writes and direct Create arguments.
- `detailed-catalog/all_layout_layers.csv` — every authored layout/layer and raw placement count.
- `detailed-catalog/all_editor_placements.csv` — every authored object's original ID/name/instance UID/location.
- `detailed-catalog/README.md` and `summary.json` — generated count tables and categorization.

The workflow `.github/workflows/audit-original-world.yml` runs it automatically after original source changes and uploads the results in the `original-world-source-exhaustive-traces` artifact.

## Building-specific catalog extension — 2026-11-21

The root-source extractor now also emits **three building-oriented datasets**, avoiding assumptions from original PNG names:

- `building_object_candidates.csv`: every name/family-classified building, interior, door, wall, roof and furniture candidate with original object IDs, frame counts, source family memberships, placed authoring layers and raw Create event references.
- `original_family_membership.csv`: every Construct source family/member pair. The **1041/1048/1049 family IDs are not independent drawable building images**, so source member IDs must be used for correct texture rectangles and collision.
- `original_world_create_actions.csv`: direct, literal System Create object actions found under the original `create_map_element` chain, retaining the original event UID and conditions. This intentionally does **not** label dynamic or indirectly created objects as absent.

**Evidence limit:** these are source-discovery tables. Generated-world building totals require original Array expression evaluation and Construct world creation semantics. The workflows regenerate these tables; the current edit has not yet been individually confirmed through a completed workflow run or Azahar visual comparison.

**Next exact building implementation gates:** resolve all house/interior/roof companion object pairs, verify every original sprite-sheet frame coordinate and origin, validate placement dimensions against Construct root frames, then complete collision/entry/door/roof/audio with matching original event ancestry. Do not mark the world complete based solely on the extractor.

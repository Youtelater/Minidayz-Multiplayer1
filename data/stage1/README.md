# Stage 1 extracted data

The complete parsed Construct project snapshot is stored in `source_snapshot/` as ordered text chunks. Run `python tools/stage1/reassemble_snapshot.py` to reconstruct `construct_project_parsed.json`. The extracted inventories and generated C++17 tables are included alongside the snapshot.

The root-level data.deobfuscated.js (the supplied deobfuscated Construct export) is the authoritative extraction source. Use root-level mp_itemtable.js and l_eng_*.xml files for item mappings and localized content. Original artwork is sourced from root-level assets/gfx, images, and gfx as referenced by the export. Never use files under Minidayz-Multiplayer-main/; that directory contains a different, newer game version. Do not inspect or use anything under `romfs/`; the user identified it as unreliable Gemini-generated material. `raw/` and `c2injt.js` are not extraction sources. Files ending in `mp.json` and non-JSON multiplayer material remain excluded from Stage 1. Original media assets are not modified.
